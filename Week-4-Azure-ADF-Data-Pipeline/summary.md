# Azure Cloud Fundamentals and Data Pipeline Implementation using ADF - Summary

## Objective

The objective of this assignment was to understand basic Azure cloud concepts and build an end-to-end data pipeline using Azure Storage Account, Blob Storage, and Azure Data Factory.

## Dataset Used

For this assignment, the Superstore dataset was used as the source CSV file. Before uploading the dataset to Azure Blob Storage, the data was analyzed using Python and Pandas.

The analysis included checking:

* Number of rows and columns
* Column names
* Data types
* Missing values
* Duplicate records
* Basic numerical summary
* Sales and profit-related information

This helped in understanding the structure and quality of the dataset before using it in the Azure pipeline.

## Azure Resources Created

The following Azure resources were created for this assignment:

* Resource Group
* Storage Account
* Blob Containers
* Azure Data Factory
* Linked Service
* Source Dataset
* Destination Dataset
* ADF Pipeline

## Resource Group

A Resource Group was created in Azure Portal to keep all assignment-related Azure resources organized in one place.

Resource Group Name:

`rg-celebal-adf-assignment`

This Resource Group contains the Storage Account and Azure Data Factory used in the assignment.

## Storage Account and Blob Containers

A Storage Account was created to store the CSV file.

Storage Account Name:

`stcelebaladfsakshisinha`

Inside the Storage Account, two Blob Containers were created:

* `source`
* `destination`

The Superstore CSV file was uploaded into the `source` container. The `destination` container was used to store the copied output file generated by the Azure Data Factory pipeline.

## Azure Data Factory

Azure Data Factory was created to build and execute the data pipeline.

Data Factory Name:

`adf-celebal-assignment-sakshisinha`

ADF Studio was explored, including the following sections:

* Author
* Monitor
* Manage

The Author section was used to create datasets and pipelines.
The Monitor section was used to check pipeline execution status.
The Manage section was used to create and manage linked services.

## Linked Service

A Linked Service was created in Azure Data Factory to connect ADF with Azure Blob Storage.

Linked Service Name:

`LS_AzureBlobStorage`

This Linked Service allowed Azure Data Factory to access the files stored in the Azure Storage Account.

## Datasets

Two datasets were created in Azure Data Factory.

### Source Dataset

Source Dataset Name:

`DS_Source_Superstore_CSV`

This dataset points to the CSV file uploaded inside the `source` Blob container.

### Destination Dataset

Destination Dataset Name:

`DS_Destination_Superstore_CSV`

This dataset points to the output file location inside the `destination` Blob container.

The destination file was named:

`copied_superstore.csv`

The schema was imported only for the source dataset. For the destination dataset, schema import was skipped because the output file did not exist before the pipeline execution.

## Pipeline Development

A pipeline was created in Azure Data Factory to copy the CSV file from the source container to the destination container.

Pipeline Name:

`PL_Copy_Superstore_Blob_To_Blob`

The pipeline included the following activities:

1. Get Metadata Activity
2. Copy Data Activity

## Get Metadata Activity

The Get Metadata activity was used to validate the source file before copying it.

The following metadata fields were checked:

* File exists
* File size
* Item name
* Last modified date

This helped confirm that the source file was available in Blob Storage before executing the copy operation.

## Copy Data Activity

The Copy Data activity was used to copy the CSV file from the `source` Blob container to the `destination` Blob container.

Source:

`source/Sample_Superstore.csv`

Destination:

`destination/copied_superstore.csv`

The Copy Data activity successfully copied the file to the destination location.

## Pipeline Execution

The pipeline was executed using Debug/Trigger in Azure Data Factory.

After execution, the pipeline status was shown as:

`Succeeded`

The execution was also verified in the Monitor section of Azure Data Factory.

## IAM Role Assignment

IAM roles were configured to manage access between Azure Data Factory and Azure Blob Storage.

The following roles were used:

* Reader
* Contributor
* Storage Blob Data Contributor

The Storage Blob Data Contributor role was assigned to allow Azure Data Factory to access and work with Blob Storage data.

## Final Output

The final output of the assignment was a successfully executed Azure Data Factory pipeline.

The CSV file was copied from the source container to the destination container.

Final copied file:

`destination/copied_superstore.csv`

## Final Pipeline Flow

Superstore CSV File
        ↓
Azure Blob Storage Source Container
        ↓
Azure Data Factory Linked Service
        ↓
Source Dataset
        ↓
Get Metadata Activity
        ↓
Copy Data Activity
        ↓
Destination Dataset
        ↓
Copied CSV File in Destination Container
```
