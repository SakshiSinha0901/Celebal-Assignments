# Week 5 Spark DataFrame Assignment

## Objective

The objective of this assignment is to understand Spark fundamentals and perform data cleaning, transformation, filtering, grouping, and aggregation using Spark DataFrames.

## Assignment Overview

This assignment focuses on Apache Spark and PySpark DataFrames. It explains why Spark is faster than traditional MapReduce and demonstrates practical DataFrame operations such as removing duplicates, handling null values, filtering data, grouping records, modifying schema, and calculating aggregations.

## Topics Covered

- Limitations of traditional MapReduce
- Advantages of Apache Spark
- In-memory computing in Spark
- Spark DataFrame concepts
- DataFrame immutability
- Removing duplicate records
- Handling null values using `.na.drop()` and `.na.fill()`
- Filtering data using conditions
- Grouping data using `groupBy()`
- Aggregation using `count()`, `sum()`, `avg()`, `min()`, `max()`, and `mean()`
- Schema modification using casting and renaming
- Shuffle and wide transformations
- Final data processing pipeline
