# Notebooks

This folder contains the Databricks notebook used to build and run the TrustGuard data quality pipeline.

Main notebook:

```text
TrustGuard_Databricks_Pipeline.ipynb
```

The notebook contains all major project steps:

1. Project setup
2. Reading uploaded raw data
3. Schema validation
4. Raw Layer creation
5. Data quality checks
6. Data cleaning and standardization
7. Rejected records handling
8. Clean Layer creation
9. Final Layer creation
10. SQL-based reports
11. Anomaly detection
12. Pipeline audit logging

This notebook is the main execution file for the project.
