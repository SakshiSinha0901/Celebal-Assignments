# Submission Checklist

Before submitting the TrustGuard project, the following items should be completed.

## Databricks Work

- Dataset uploaded to Databricks.
- Databricks notebook created.
- Serverless compute connected.
- Raw Layer table created.
- Clean Layer tables created.
- Final Layer tables created.
- DQ report generated.
- Rejected records generated.
- SQL reports executed.
- Anomaly log created.
- Pipeline log created.

## Local Project Folder

- Dataset added inside `data/raw`.
- Databricks notebook exported inside `notebooks`.
- Documentation files added inside `docs`.
- Screenshots added inside `screenshots`.
- `README.md` completed.
- `COMMANDS_TO_RUN.md` completed.
- `requirements.txt` added.

## Screenshots

Recommended screenshots:

- Dataset uploaded in Databricks
- Raw table output
- Data quality report
- Rejected records
- Clean transactions
- Final transactions
- City sales report
- Top customers SQL query
- Payment method report
- Anomaly log
- Pipeline log
- SHOW TABLES output

## GitHub

- All files added.
- Commit created.
- Project pushed to GitHub.
- Repository link ready for submission.
